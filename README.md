# gs1-datamatrix-creator

Генерация **GS1 Data Matrix (ECC 200)** по коду маркировки системы «Честный знак»
без нативных зависимостей и без обращения к ГИС МТ. Библиотека + CLI + HTTP-сервис.

Скрипт сам разбирает строку КМ, проверяет её структуру, кодирует данные
(ASCII-режим, как в системе «Честный знак» — сверено побитово с эталонным СИ),
считает коррекцию Рида — Соломона и размещает модули по ISO/IEC 16022.
На выходе — PNG и SVG; HTTP-сервис дополнительно отдаёт JSON с разобранными полями.

## Возможности

- Разбор и строгая валидация КМ: GTIN-14 с контрольной цифрой, серийник CSET 82,
  крипточасти 91+92 (base64, 44/88) или 93; «сырой» вид, скобочный вид,
  восстановление границ полей без GS.
- Все 24 квадратных и 6 прямоугольных размеров ECC 200 (Reed-Solomon на чистом Python).
- Вывод PNG (Pillow) и SVG (stdlib), ASCII-предпросмотр.
- HTTP-сервис FastAPI: JSON/PNG/SVG, валидация, дашборд тестирования на `/`.
- Побитовая сверка с эталонным СИ «Честного знака» (0% расхождения, ECC сходится).

## Что важно понимать

**Скрипт не создаёт коды маркировки.** Криптохвост (AI 91 + AI 92 либо AI 93)
формируется только ГИС МТ при заказе кодов и содержит подпись, которую невозможно
вычислить локально. На вход подаётся уже полученная строка КМ — из выгрузки
«Честного знака» (CSV, PDF, API), из файла заказа или из сканера.

AI 10 (номер партии) и AI 17 (срок годности) в Data Matrix **не входят** — они
печатаются на этикетке обычным текстом рядом с символом.

## Установка

```powershell
uv sync                 # только runtime (Pillow)
uv sync --extra dev     # плюс zxing-cpp для самопроверки, декодирования и HTTP-тестов
uv sync --extra web     # плюс FastAPI и Uvicorn для HTTP-сервиса
```

Запуск без установки:

```powershell
uv run gs1dm --help
```

Требуется Python 3.12+. Runtime-зависимости: Pillow (PNG) и, для HTTP-сервиса,
FastAPI + Uvicorn; ECC 200, разбор GS1 и SVG реализованы на стандартной
библиотеке.

## Использование

### Один код

```powershell
uv run gs1dm create "(01)04811289005596(21)5PoVL5(93))H7P" -o labels --png --svg
uv run gs1dm show  "(01)04811289005596(21)5PoVL5(93))H7P" --ascii
```

### Пакетно из файла

```powershell
uv run gs1dm create --input codes.csv --outdir labels --png --svg --column "КМ"
uv run gs1dm validate --input codes.txt
```

Поддерживаются `.txt` (по одному коду в строке, `#` — комментарий), `.csv`/`.tsv`
(столбец ищется по имени `КМ`/`код`/`code`/`km` или задаётся через `--column`)
и `.json` (массив строк или объект с массивом).

### Параметры вывода

| Параметр | По умолчанию | Назначение |
| --- | --- | --- |
| `--png` / `--svg` | PNG | Форматы; можно указать оба |
| `--scale` | 10 | Пикселей на модуль (PNG) |
| `--dpi` | 300 | DPI в метаданных PNG |
| `--quiet-zone` | 2 | Свободное поле вокруг символа, в модулях |
| `--module-mm` | 0.5 | Размер модуля для SVG, мм |

Размер PNG = `(сторона символа + 2 × quiet-zone) × scale`. Для 22×22 при
масштабе 10 это 260×260 px; чтобы при печати модуль был не меньше 0.2555 мм
(требование к печати КМ), считайте масштаб от DPI принтера.

### Приём кодов

Принимаются оба вида строки:

- «сырой», как в выгрузке ГИС МТ: `0104811289005596215PoVL5\x1d93)H7P`
  (разделитель GS — ASCII 29; текстовые записи `\x1d`, `<GS>`, `[GS]` тоже
  понимаются);
- «человекочитаемый»: `(01)04811289005596(21)5PoVL5(93))H7P`.

Если разделитель GS потерялся, границы полей восстанавливаются по известным
длинам AI. Скобки и прочие допустимые в серийном номере спецсимволы разбор не ломают.

Элементная строка формируется по правилам системы «Честный знак»
(сверено с эталонным СИ, выданным ЦРПТ): разделитель GS (ASCII 29) ставится
только после полей переменной длины — после серийного номера и между
крипто-полями. После GTIN (AI 01, фиксированные 14 цифр) разделитель не
ставится: `01<GTIN>21<серийник><GS>91<ключ><GS>92<код>`. В самом символе
ведущее кодовое слово — FNC1 (232), что делает символ «GS1 Data Matrix»;
разделители GS внутри данных кодируются как обычный ASCII-символ —
именно так делает система «Честный знак» (подтверждено побитовой сверкой
с эталонным СИ: кодовые слова и пиксели совпадают один в один).

### Валидация (строгая, по умолчанию)

Проверяется: контрольная цифра GTIN, длины и порядок AI, набор символов
(AI 21 и AI 91/93 — CSET 82, AI 92 — base64), наличие крипточасти, длина AI 92
(44 или 88). При ошибке **символ не создаётся**, команда возвращает код 1.

Код идентификации без крипточасти (например, `(01)00000046209849(21)5000000005NgF`)
отвергается; при необходимости его можно пропустить через
`--allow-missing-crypto` — но печатать такой код на товаре нельзя.

## Что именно кодируется

В символ попадает элементная строка GS1 без FNC1:

```
01 <GTIN-14> GS 21 <серийный номер> [GS 91 <4 симв.> GS 92 <44|88 симв.> | GS 93 <4 симв.>]
```

При кодировании: первым кодовым словом идёт FNC1 (232) — это и делает символ
«GS1 Data Matrix». Разделители GS внутри данных кодируются как обычный
ASCII-символ (0x1D + 1 = 30) — так же, как в эталонных кодах «Честного знака»
(чистое ASCII-кодирование, Annex P; побитовая сверка с эталонным СИ
`out/user_dm.png` — совпадение 100%, ECC-проверка эталона сходится).
Дальше идут пары цифр 130..229, одиночные символы c+1, заполнители
PAD 129 с псевдослучайным смещением.

## Программный интерфейс

```python
import gs1dm

bar = gs1dm.create("(01)04811289005596(21)5PoVL5(93))H7P")
print(bar.symbol.size_label)      # '22x22'
print(bar.element_string)         # '0104811289005596\x1d215PoVL5\x1d93)H7P'

gs1dm.render_png(bar, "code.png", scale=10, dpi=300)
gs1dm.render_svg(bar, "code.svg", module_size_mm=0.5)
```

Полезные объекты: `gs1dm.MarkingCode` (разобранные поля), `gs1dm.SymbolInfo`
(ёмкость, блоки RS), `gs1dm.Barcode.matrix` (`list[list[bool]]`).

## HTTP-интерфейс (FastAPI)

Сервис принимает уже полученную строку КМ и отдаёт готовый символ. Запуск:

```powershell
uv run gs1dm-web
```

Сетевые настройки берутся из `.env` в корне проекта:

```dotenv
GS1DM_HOST=0.0.0.0   # 0.0.0.0 — доступ с любого IP; 127.0.0.1 — только localhost
GS1DM_PORT=8000
```

Ключи `--host`/`--port` имеют приоритет над `.env`. CORS открыт для всех
origin (`allow_origins=["*"]`) — дашбордом можно пользоваться с любой машины.
При доступе извне откройте порт в брандмауэре Windows.

Интерактивная документация (Swagger UI): `http://127.0.0.1:8000/docs`.
Дашборд тестирования API: `http://127.0.0.1:8000/` — форма ввода КМ
(строкой или полями), параметры рендера, предпросмотр PNG/SVG, результаты
`/api/create` и `/api/validate` и журнал всех запросов.

| Эндпоинт | Назначение |
| --- | --- |
| `POST /api/create` | Разобрать КМ, вернуть поля, элементную строку, размер символа и base64 PNG + SVG |
| `POST /api/png` | Сразу PNG-изображение (`image/png`) |
| `POST /api/svg` | Сразу SVG-документ (`image/svg+xml`) |
| `POST /api/validate` | Только проверка строки КМ без генерации |
| `GET /health` | Проверка живости |

Пример запроса к `/api/create`:

```json
{
  "code": "(01)04640711961304(21)5;I)DmC:IDt*L(91)EE12(92)4a8GsyItTVweCsj65+Wk5AxvQD6NnNAcmMIKSsLGAek=",
  "scale": 10,
  "dpi": 300
}
```

Вместо `code` можно передать поля по отдельности — `gtin`, `serial` и
крипто-часть (`ai91` + `ai92` либо `ai93`): строка соберётся автоматически.
Ошибки валидации возвращаются с кодом 422 в `detail.errors`; ответы
`/api/validate` всегда 200 с полями `valid` и `errors`.

Тесты HTTP-слоя: `uv run python tests/test_web.py` (10 тестов через
`fastapi.testclient`, включая round-trip PNG через zxing-cpp, RAW-код из БД
и дашборд).

## Проверка корректности

```powershell
uv run python tests/selftest.py             # round-trip на реальных структурах КМ + 12 случайных
uv run python tests/test_all_sizes.py       # все 24 квадратных размера, включая 144x144 (10 блоков RS)
uv run python tests/test_rectangular.py     # все 6 прямоугольных размеров
uv run python tests/test_gs1_conformance.py # структура GS1 (]d2), байты и размеры символов
uv run python tests/test_chz_reference.py   # побитовая сверка с эталонным СИ «Честного знака»
```

Тест делает round-trip: генерирует PNG и декодирует его обратно через
zxing-cpp, сверяя байты с исходной элементной строкой (включая GS). Проверены
все 30 размеров символов ECC 200; отдельно проверяется отлов ошибок (битая
контрольная цифра, отсутствие крипточасти, кириллица).

## Ограничения

- Квадратные символы (по умолчанию); прямоугольные — через `--allow-rectangular`.
- Только ASCII-кодирование (Annex P). Для КМ этого достаточно: латиница, цифры,
  несколько спецсимволов — и именно так кодирует «Честный знак» (проверено
  побитово). C40/Text/X12/EDIFACT/Base256 не реализованы.
- Кириллица в Data Matrix по ISO 8859-1 невозможна — валидация её отклоняет.
- Формат GS1 Data Matrix не выводится в PDF; при необходимости вставьте SVG
  в макет этикетки.
